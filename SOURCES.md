# Scientific and image sources

1. NASA/JPL Solar System Dynamics, approximate major-planet coordinates and 1800–2050 orbital elements: https://ssd.jpl.nasa.gov/planets/approx_pos.html
2. NASA/JPL Horizons (high-precision source for planned future upgrade; current prototype does NOT call this service): https://ssd-api.jpl.nasa.gov/doc/horizons.html
3. NASA Image and Video Library search (remote photographic assets, no API key): https://images.nasa.gov/docs/images.nasa.gov_api_docs.pdf
4. NASA Hubble Messier catalog (object names/types): https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/
5. NASA Eclipse event reference: https://science.nasa.gov/eclipses/future-eclipses/
6. International Meteor Organization calendar (meteor shower windows; verify peak before observing): https://www.imo.net/calendar/
7. Android developer widget update documentation: https://developer.android.com/develop/ui/views/appwidgets/advanced

## Media attribution
Photographs found by the NASA Image and Video Library are linked to the external NASA record. NASA content may contain third-party copyrighted material: observe the credit and license information on each result before redistribution. The app does not bundle or republish remote NASA photographs.
